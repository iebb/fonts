Panorama Gothic Small Seal — centerline weight prototype

64 characters: U+3D000–U+3D03F.
wght 300–700: Light 30, Regular 43, Medium 50.333, Bold 65 pen units.
All masters use identical editable centerlines and fixed 1024-unit advances.
Only the shared pen width changes; no outline-offset operation is used.
Dense counters and gaps can close at heavier weights and need optical review.
Character forms remain experimental; historical stroke order is unverified.
