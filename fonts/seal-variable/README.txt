Panorama Gothic Seal Variable — 64-glyph weight study

Experimental wght axis: 300 Light, 400 Regular, 500 Medium, 700 Bold.
Install PanoramaGothicSealVariable.ttf or use the included static fonts.
U+3D000–U+3D03F; existing generated drawing identities are preserved.
Regular400 uses exactly the original outlines and metrics. All advances
remain 1024 units. Other weights use compatible normal-offset outlines.
This is a weight visualization prototype, not a finished script design.
See manifest.json for measured checks and limitations. OFL 1.1.
